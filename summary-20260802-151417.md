# Racing United Project Summary

Generated: 2026-08-02 15:14:17 (Europe/Ljubljana)

## Overview

Racing United is an open-source racing simulator concept focused on automotive history and culture. The project aims to cover organized motorsport, clandestine racing culture, vehicle modification, tuning, and varied driving experiences. The repository currently contains an early Windows prototype consisting of a launcher and a basic OpenGL engine/demo.

## Repository structure

- `Engine/Launcher/` — Visual C++ launcher application.
- `Engine/HeritageEngine/` — Visual C++ engine/demo application.
- `Modules/RacingUnited/` — Module descriptor and runtime settings.
- `Assets/` — Orbitron font and Racing United 3D logo material file.
- `ThirdParty/` — GLFW 3.4 binaries/headers, GLAD, and Dear ImGui source/backends.
- `README.md` — Short project description and Discord community link.
- `RacingUnited_GitHub.png` — Repository/project banner image.

## Main components

### Launcher

`Engine/Launcher/launcher_main.cpp` implements a borderless custom-window launcher using GLFW, OpenGL, GLAD, and Dear ImGui. It:

- Scans `Modules/` for folders containing `module.ini` files.
- Parses module name, version, author, description, and executable metadata.
- Presents module selection and launch controls.
- Saves video/audio settings to the selected module’s `settings.ini`.
- Provides video, audio, and placeholder input settings tabs.
- Can create a Windows desktop shortcut for a selected module.
- Uses the bundled Orbitron font and a dark custom UI theme.

The configured Racing United module is version `0.1`, authored by `naik-gamedev`, with the description “The virtual heritage of racing”. Its executable is configured as `HeritageEngine.exe`.

### Heritage Engine

`Engine/HeritageEngine/HeritageEngine/main.cpp` is an OpenGL 4.6 core-profile demo. It currently provides:

- GLFW window creation with a borderless custom title bar.
- GLAD OpenGL function loading.
- Dear ImGui integration for UI rendering.
- A small hand-written math layer for vectors, matrices, and perspective projection.
- An OBJ mesh loader with indexed geometry and normal support.
- Basic vertex/fragment shaders with ambient, diffuse, specular, and rim lighting.
- Interactive 3D logo orbiting with mouse drag and zooming with the scroll wheel.
- F11 cycling between windowed, borderless, and exclusive fullscreen modes.
- ESC and title-bar controls for closing, plus a minimize button.

The intended displayed asset is `Assets/RacingUnited_3D_Logo.obj`, but the current repository listing contains the accompanying `.mtl` file and no `.obj` file, so the demo may fail to load its mesh until that asset is restored or the path is changed.

## Current maturity and considerations

This is an early prototype rather than a complete racing game. The repository contains launcher/UI infrastructure and a rendered logo scene, but no visible vehicle, track, physics, racing rules, audio implementation, or gameplay systems.

The Visual Studio projects and source code contain hard-coded absolute paths beginning with `F:/Racing United/SourceCode/GitHub/RacingUnited`. These paths will need to be replaced with repository-relative/runtime-resolved paths for the project to build and run on another machine. The module executable string also appears malformed in the source listing (`HeritageEngine.exeresolution` immediately follows it), so the metadata file should be checked for a missing line break. No automated tests or cross-platform build configuration are present.
