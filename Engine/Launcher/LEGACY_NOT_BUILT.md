# Legacy standalone launcher

This directory is retained only as historical/reference source. It is no longer part of the active Heritage Engine solution or build flow.

Heritage Engine now uses the single `HeritageEngine.exe` process, which discovers/loads the selected game/module itself. New launcher/settings work must target the engine-owned startup/settings flow rather than adding features here.

If historical source retention is no longer useful, version-control history is the preferred archive and this directory may be removed in a later explicit repository-pruning pass.
