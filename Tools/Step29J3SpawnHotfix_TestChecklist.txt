Heritage Engine - Step 29J.3a Blender OBJ Spawn Marker Hotfix

1. Extract the hotfix over the current Step 29J.3 project.
2. None of your creator OBJ files are included or replaced.
3. Run Tools\BuildAndRunStep29J3SpawnHotfix.cmd.
4. Open prototype -> SCENE -> WORLD -> LOAD / RELOAD PLAYER SCENE.
5. With a Blender object named SPAWN_PLAYER in PlayerScene_Collision.obj:
   - Spawn source should read: marker
   - Vehicle should reset at that authored marker rather than the auto-ground AABB center.
6. This hotfix specifically fixes Blender OBJ exports that write both:
     o SPAWN_PLAYER
     g <some export/material/group name>
   The importer now keeps the Blender object name as authoritative identity.
7. If Spawn source STILL reads auto-ground, the exported OBJ does not contain a usable SPAWN_PLAYER object/face set. In that case send PlayerScene_Collision.obj; do not keep guessing in Blender.
