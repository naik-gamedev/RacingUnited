HERITAGE ENGINE - STEP 29H TEST CHECKLIST
=========================================

1. Run Tools\BuildAndRunStep29H.cmd.
   Expected: repository validation passes, Release x64 rebuild succeeds, and
   the freshly built engine launches Racing United.

2. Open VEHICLE > TIRES > PROFILES.
   Expected native readback:
     FL / FR = prototype_road_front
     RL / RR = prototype_road_rear
   The front and rear numerical load/stiffness/inertia values should differ.

3. Click APPLY FRONT TEMPLATE TO ALL WHEELS.
   Expected: all four rows report prototype_road_front and identical native
   tire readback values.

4. Click RESTORE DEFINITION FRONT / REAR PROFILES.
   Expected: front and rear assignments separate again.

5. Open BASIC or CURVE and move one slider slightly.
   Expected: this deliberately invokes the legacy all-wheel SetTireModel path;
   all wheel labels change to manual_all_wheels.
   Return to PROFILES and click RESTORE DEFINITION FRONT / REAR PROFILES.

6. Drive on dry asphalt and through the Step 29F split-grip/surface tests.
   Expected: steering, drivetrain, ABS/TCS, combined-slip telemetry, and
   per-wheel surface detection still operate.

7. Optional API verification:
   ABOUT/SAFETY API dump should contain:
     Vehicle.SetWheelTireModel
     Vehicle.GetWheelTireModel

If anything fails, send the first build error or a screenshot plus:
UserData\Diagnostics\step29h_build_and_run.txt
Build\Reports\ValidationReport.txt
