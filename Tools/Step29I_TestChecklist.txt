HERITAGE ENGINE - STEP 29I TEST CHECKLIST
==========================================

Goal: creator-visible vehicle OBJ import without changing vehicle physics.

1. Run Tools\BuildAndRunStep29I.cmd.
2. Enter the prototype scene.
3. Open VEHICLE > VISUAL.
4. The car should render using:
      Vehicles/Player/PlayerCar.obj
   The shipped file is intentionally just the familiar low-poly placeholder.
5. Move Visual offset X/Y/Z, rotation X/Y/Z, and uniform scale.
   Only the rendered mesh should move/rotate/scale. The native car should keep
   driving and the physics wheel/contact positions must remain unchanged.
6. Press RESET VISUAL ALIGNMENT. The placeholder should return to its authored
   position.
7. Toggle Hide prototype wheel cylinders, then return to VEHICLE > DRIVE.
   The black prototype wheel cylinders should obey that preference.
8. Press USE FALLBACK LOW-POLY and USE PLAYER CAR OBJ. Both should render.
9. Optional / exciting test:
      - Export any authored car as OBJ.
      - Replace Modules\RacingUnited\Assets\Vehicles\Player\PlayerCar.obj.
      - Keep the engine open.
      - The mesh should update after the file write time changes; no C++ rebuild
        is required for geometry iteration.
10. Drive the car. Steering, drivetrain, tire surfaces and per-wheel tire data
    should behave exactly as Step 29H.

Current visual limitation: a whole-car OBJ is rigid. If it contains authored
wheels, they move with the body but do not independently spin/steer yet.
