# CLOUDURP15AT – Neutral Noon Clouds

## Summary
Follow-up to CLOUDURP15AS.

## Changes
- dense noon cloud bodies are pulled toward neutral white/grey;
- blue sky tint is reduced strongly in cloud interiors;
- only thin/translucent cloud edges retain a very subtle sky-colour influence;
- sunset/sunrise cloud colour response remains strong because neutralisation fades out at low Sun angles;
- existing three-band sky/horizon gradient remains unchanged.
