# STUDIO26 — Borderless Studio, Blender Fly Navigation, Authored Broadcast Cameras

STUDIO26 fixes the remaining light Windows caption by matching Heritage Engine's real window architecture: `HeritageStudio.exe` now creates an undecorated GLFW window and renders/owns its dark title bar with ImGui. The Studio chrome supplies drag, minimize, maximize/restore, close, and border resizing instead of asking DWM to recolor the native caption.

The shared Scene / Race / Traffic / Gameplay 3D viewport gains Blender-style modal fly navigation on **Shift+`** (grave accent). Entering fly mode captures the mouse for unrestricted look, forces perspective for the modal session, and keeps the existing orbit camera representation coherent when the modal tool exits. W/A/S/D move along the view, Q/E move vertically, the wheel changes movement speed, Shift is a fast multiplier, and Alt is a precision multiplier. LMB or Enter confirms the new view; RMB or Escape cancels and restores the exact pre-fly view. The confirmation click is consumed so it cannot also select/place an authored object.

STUDIO26 also connects the already-authored **Replay Camera** race marker to STUDIO25's native FP64 broadcast director. A Replay Camera marker now defaults to a 120 m activation radius. In the Race inspector, **SET REPLAY CAMERA FROM CURRENT VIEW** copies the current editor camera position to the marker, which makes Shift+` a practical camera-placement workflow. Runtime Trackside replay selects the nearest layout-applicable Replay Camera whose activation radius contains the reviewed cars. The camera remains fixed at the authored position and dynamically pans toward the replay target. If no authored station applies, the STUDIO25 procedural trackside camera remains the fallback. Switching between authored stations performs a cut rather than smoothing a camera through scenery.

No HGAME or HRACE format bump is required: Replay Camera marker position, heading, radius, order and layout scope were already serialized and published. This milestone gives existing data real runtime meaning rather than introducing a parallel camera asset format.
