# Environment lighting and reflections (GFX6)

> **GFX7 update:** the procedural environment is now also drawn as the visible sky and follows a controllable day/night clock. See `SKY_DAY_NIGHT.md`.

GFX6 gives the Heritage material renderer its first environment-lighting path.
The goal is to make the material inputs added in GFX1-GFX5 actually react like
materials instead of relying only on the old directional/hemisphere preview
shader.

## What GFX6 adds

- A renderer-owned cubemap environment resource.
- A deterministic procedural sky/ground environment so every module gets a
  usable reflection source without shipping a new texture asset.
- Linear floating-point cubemap storage (`RGB16F`).
- A generated mip chain used as the first roughness-aware reflection
  approximation:
  - smooth surfaces sample sharp low mip levels;
  - rough surfaces sample progressively blurred higher mip levels.
- Environment diffuse lighting.
- Environment specular reflections.
- Cook-Torrance / GGX direct-light response using the existing:
  - Diffuse / Base Color
  - Normal
  - Roughness
  - Metallic
  - Specular
  - AO
  - Emissive
  - Opacity
  - vertex color inputs.

The diffuse/base-color texture is still allowed to contain authored baked
shading. GFX6 does not force a "pure albedo only" workflow.

## AO behavior

The two AO workflows remain complementary:

- greyscale vertex color can carry broad baked scene/contact AO and already
  multiplies the visible base material;
- an AO texture can carry finer texel-level occlusion and now attenuates the
  environment-light contribution.

This matches the intended workflow of using vertex AO for large scene-scale
shading while retaining a texture AO map for fine detail.

## Why the environment is procedural first

This milestone establishes the renderer boundary without adding another asset
format dependency. `EnvironmentMap` is a separate graphics resource so later
milestones can replace or supplement the procedural cube with:

- HDR / EXR / equirectangular environment images;
- module-authored skies;
- local reflection probes;
- time-of-day environment generation.

Material code does not need to change when those sources arrive.

## Current limitation

The roughness mip chain is a practical first approximation generated by normal
cubemap mipmapping. It is not yet a full GGX importance-sampled specular
prefilter with a split-sum BRDF lookup table. That higher-quality path can be
added later behind the same `EnvironmentMap` resource.

GFX6 originally stopped at a lighting/reflection source. GFX7 now draws the
same procedural environment as the visible sky and updates it through the shared
day/night `EnvironmentSystem`.
