# CLOUDURP15AM – Horizon Blend + Cloud Fill

## Summary
Follow-up to CLOUDURP15AL.

## Changes
- far low-LOD cloud search remains capped at 500 km;
- brighter/whiter daylight fill for cloud faces away from the Sun;
- stronger horizon/aerial blending for distant shallow-angle clouds;
- cloud transmittance slightly relaxed near the far horizon so cloud bands soften into haze.

## Intent
Match the reference behaviour where distant clouds visually melt into the horizon instead of stopping with a hard lower edge, while also keeping general daytime cloud bodies brighter.
