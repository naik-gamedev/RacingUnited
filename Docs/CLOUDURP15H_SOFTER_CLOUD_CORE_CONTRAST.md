# CLOUDURP15H — softer cloud core contrast

Targeted lighting tuning requested after CLOUDURP15G:

- noon sun cloud-illumination boost reduced to 1.10x
- cloud interior ambient multiplier reduced to 1.35
- thickness darkening reduced to 0.15
- extinction lowered to 0.010..0.026 so cores stay much less dark
- keeps the gradual rain-to-cloud response from CLOUDURP15G
