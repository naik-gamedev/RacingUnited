# CLOUDURP15T – Yellow Sun, White Moon, Stronger Glow

## Summary
A tuning pass that pushes both celestial bodies toward a much more luminous stylised presentation.

## Changes
- Sun kept near the current ~2x apparent size but shifted yellower overall;
- Sun local bloom greatly intensified so the disc shape is now barely visible except in the most favourable conditions;
- Moon visual body shifted whiter;
- Moon local bloom intensified substantially, with a larger white/silver halo.

## Intent
Match the user's request for a much more obviously glowing Sun and Moon while avoiding a whole-scene bloom pass.
