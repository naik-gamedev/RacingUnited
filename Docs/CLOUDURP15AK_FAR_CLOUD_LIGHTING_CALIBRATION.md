# CLOUDURP15AK – Far Cloud Lighting Calibration

## Summary
Keeps the full 2,000 km spherical-Earth far-cloud search from CLOUDURP15AJ while correcting over-bright cloud lighting.

## Changes
- direct Sun irradiance on volumetric clouds reduced substantially;
- ambient cloud lift reduced moderately;
- distant clouds now receive view-path atmospheric extinction based on cloud distance;
- horizon clouds blend toward live sky colour rather than remaining brilliant white;
- spherical Earth curvature and 2,000 km far-search budget remain unchanged.
