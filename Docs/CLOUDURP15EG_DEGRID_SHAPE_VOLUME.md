# CLOUDURP15EG — De-grid Shape Volume

The residual horizontal banding survived higher raymarch sample counts, midpoint sampling, four occupied microsteps and rotated erosion sampling. That points upstream of integration.

The 128^3 base shape volume spans 100 km at shape scale 5, or about 156.25 m per source voxel. A 5 km storm cloud therefore traverses only about 32 base-shape voxels vertically, closely matching the observed band spacing.

CLOUDURP15EG samples the same periodic shape volume through two fully rotated coordinate frames and blends them. This removes a coherent world-height voxel stack without creating a second cloud field. Shadow density uses the same de-gridded shape path. The vertical preset curve LUT is increased from 64 to 256 samples as a cheap secondary guard against profile stepping.
