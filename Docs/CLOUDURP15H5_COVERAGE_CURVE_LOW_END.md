# CLOUDURP15H5 — coverage curve low-end calibration


The cloud-cover UI is treated as perceived sky fraction rather than a linear procedural-noise threshold. 0% remains exactly clear. The first two percent now have dedicated anchors so 0.5–1% can produce sparse isolated clouds. 50% maps to approximately the cloud-formation authority that H4 used at 80%, while 100% remains full overcast.
