# STUDIO07 — Blender 5.2 Authoring UX

Baseline: Blender 5.2 LTS default keymap/layout conventions, extended with Racing United game-authoring object types.

This milestone changes Studio navigation/layout conventions rather than embedding Blender or copying Blender source. Heritage retains its own runtime/editor implementation and data formats.

Core conventions: top workspace strip; 3D Viewport + Outliner + Properties layout; MMB orbit; Shift+MMB pan; Ctrl+MMB/wheel zoom; Numpad 1/3/7 and 5; G/R/S modal transforms; X/Y/Z constraints; Shift+A add; Shift+D duplicate; X/Delete; T and N viewport regions.
