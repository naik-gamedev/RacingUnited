# CLOUDURP15H8 — cloud layer variation and randomness

Goal: preserve H7 coverage while making the sky feel less uniform.

- some cloud groups live lower and some higher
- some are flatter while others are deeper/taller
- shape scale and erosion vary regionally so clouds do not all read as the same species
- keeps H7 startup weather, visible-linear coverage, 2000 km span, and tuned lighting
